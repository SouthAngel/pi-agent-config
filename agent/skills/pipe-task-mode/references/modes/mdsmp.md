# mdd —— 写设计文件（不实施）

首词是 `mdsmp` 时使用本文件。

## 做什么

1. 分析用户输入，无输入则分析上下文
1. 判断用户意图，目标是哪些文件，主要目的是什么（精简/重构）
1. 根据用户意图，跳转到 精简/重构 章节

## 如何判断用户意图

- 如果 带有用户输入，且输入文本明确含有 重构/重写/rewrite
- 否则 按精简意图操作

## 精简

- 逐条分析md内容，判断有无可能精简或合并相似项，提炼精简重写

## 重构

- 逐文件分析md内容，重新理解内容，重新安排章节布局，写到新的文件 <原文件>.rect.md
- 删除原文件，重命名上述文件到原始文件名

## 限制

- 仅允许修改md文件，不允许修改其它格式文件
