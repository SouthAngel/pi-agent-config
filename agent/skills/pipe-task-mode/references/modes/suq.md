# suq —— 建议模式（只读）

首词是 `suq` 时使用本文件。用户要的是**建议**，不是你动手。

## 1. 如何输出

- 有序号与title说明
- 按收益最大排序

## 2. 只读边界

**允许**：读文件、列目录、搜索（grep / glob）、`git log` / `git show` / `git diff`、`--help` / `--version`。

**禁止**：build / test / lint / format / codegen / install，以及任何写盘或改索引的命令（含会刷新索引的 `git status`、`git add`、`git stash`）。

- **只为取得当前状态而触发的命令一律不跑**：测试现在过不过、构建现在报不报错、格式化会改什么，都属于执行；只读命令只在需要确认「位置」、引用关系或变更来历时跑。
- 不写、不改、不删任何文件，含临时脚本、`docs/` 下的计划与设计文件。
