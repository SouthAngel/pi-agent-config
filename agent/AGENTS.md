# 全局行为规则

## 工具使用
- 搜索文件优先 fd，文本优先 rg
- 长任务评估耗时并带超时，后台脚本必须有退出兜底（setTimeout强制 exit），否则挂死事件循环
- 测试不超过 2 轮，不通过则停止并报告
- 2+工具连续调用时用 `codemode` 批量处理，否则直接调用禁止使用 `codemode`

## 工作方式
- **用户以 `提问/建议/检查/分析` 形式发言时只读运行**：可查看文件、搜索、执行只读命令，
  但不得修改/新建/删除任何文件，也不得触发写操作（构建、格式化、迁移等）；
  确需改动时先说明方案，等用户明确要求执行再动手
- 多次edit合并成一次write
- 如果你有更好的方案，提出来并说明理由
- 给出的建议被用户认可后直接执行，不再重复确认；完成后逐项报告做了什么、跳过什么及理由
